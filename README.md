# ระบบบริหารข้อมูลคดีและพื้นที่เสี่ยง (อิงพื้นที่ สน.ลุมพินี)

โปรเจกต์รายวิชา 341314 Computer Programming

## ปัญหาที่แก้
คนร้ายก่อเหตุข้ามพื้นที่ แต่ข้อมูลแต่ละ สน. แยกกัน ทำให้มองไม่เห็นความเชื่อมโยง
ระบบนี้บันทึกคดี 2 กลุ่มในที่เดียว และเชื่อมโยงด้วย "จุดร่วม":
- **ไซเบอร์** (บัญชี/ไลน์/เบอร์) → แผนผังสำหรับงาน **มวลชนสัมพันธ์**
- **คดีในพื้นที่** ลัก/วิ่งราว/ชิง/ปล้น/จลาจล (ทะเบียนรถ/ลักษณะคนร้าย) → แผนผังสำหรับ **บริหารสายตรวจ**

## ติดตั้งและรัน
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
เปิดครั้งแรกสร้างฐานข้อมูล `policelink.db` พร้อมข้อมูลตัวอย่างให้เอง

## ไฟล์
| ไฟล์ | หน้าที่ |
|------|---------|
| `database.py` | schema 2 กลุ่มคดี + CRUD + ตรรกะเชื่อมโยง + จุดเสี่ยง + ขอบเขต |
| `geo.py` | อ่านไฟล์ขอบเขต KML/KMZ/GeoJSON |
| `map_view.py` | สร้างแผนที่จริง (folium) 2 แผนผัง |
| `seed_data.py` | ข้อมูลตัวอย่าง (สน.ลุมพินี + ข้างเคียง, คดี 2 กลุ่ม, จุดเสี่ยง) |
| `app.py` | หน้าจอทั้งหมด (Streamlit) |
| `.streamlit/config.toml` | ธีมสว่าง |

## หน้าจอ
แดชบอร์ด · บันทึกคดี (เลือกกลุ่ม, ประเภท "อื่น ๆ" พิมพ์เองได้) ·
จัดการ/แก้ไขคดี (แก้+ลบ) · แผนผังไซเบอร์ · แผนผังสายตรวจ (กรองช่วงเวลา) ·
จัดการพื้นที่/จุดเสี่ยง (แก้สถานี/พิกัด, เพิ่ม-ย้าย-ลบจุดเสี่ยงในตาราง, นำเข้า KML) · ค้นหา

## ขอบเขตพื้นที่ (หลาย สน.)
ระบบฝังขอบเขตจริงของ สน.ลุมพินี + เขตติดต่อ (ปทุมวัน พญาไท มักกะสัน ทองหล่อ ทุ่งมหาเมฆ) ไว้แล้ว
แต่ละพื้นที่วาดบนแผนที่คนละสีพร้อมป้ายชื่อ หมุด สน. วางที่จุดศูนย์กลางพื้นที่ และคำนวณทิศอัตโนมัติ
อัปเดต/เพิ่มได้ที่แท็บ "ขอบเขตแผนที่ (KML)" โดย export KML จาก Google My Maps (รองรับหลาย สน. ในไฟล์เดียว)

## ข้อควรระวัง (เขียนในรายงานหัวข้อ "แนวทางพัฒนาต่อ")
ข้อมูลผู้เสียหาย/ผู้ต้องสงสัยเป็นข้อมูลส่วนบุคคล หากใช้งานจริงต้องปฏิบัติตาม PDPA
